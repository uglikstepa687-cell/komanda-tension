# НАТЯЖЕНИЕ

Игра для FEIS Game Jam 2026 (тема: Roles Reversed).

**Команда:** Komanda

Вы — страховочный канат на отвесной ледяной стене. Три самоуверенных восходителя решили покорить пик, и вам нужно сбросить каждого рывком в момент перехвата.

- Играть в браузере: https://uglikstepa687-cell.itch.io/natyazhenie-feis-game-jam-2026
- Исходный код: https://github.com/uglikstepa687-cell/komanda-tension

## Управление
- Пробел / W / ↑ / ЛКМ: копить натяжение (отпустить — рывок).
- E / Enter: рывок немедленно.
- S / ↓: ослабить канат.
- Q: «лавина ауры» (когда шкала заполнена).
- P / Esc: пауза. M: звук. R: перезапуск.

## Запуск локально
Откройте `index.html` в браузере.
