# ASSETS

Сторонние ассеты в проекте не используются.

- Графика: рисуется кодом на HTML5 Canvas и CSS, внешних изображений нет.
- Звук: генерируется кодом через Web Audio API, аудиофайлов нет.
- Шрифты: системные, внешние шрифты не подключаются.
- Библиотеки и движки: не используются, вся игра — один файл `index.html`.
